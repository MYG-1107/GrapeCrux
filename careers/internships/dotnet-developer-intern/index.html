About the opportunity

What this role is about

Learn modern .NET application development by assisting with backend and application tasks. Build confidence with C#, APIs, databases, testing and maintainable code.

GrapeCrux values practical problem-solving, clear communication and responsible engineering. The work is shaped around business needs, user outcomes and the quality of the solution delivered.

Before you apply

Use Job ID GC-IN-005 in any follow-up about this opportunity. The application email includes this reference automatically.

GrapeCrux does not charge applicants any application or recruitment fee.

What you'll do

Responsibilities

  • Assist with small application features in C# and .NET.
  • Help implement or test API endpoints and request/response validation.
  • Work with SQL queries or database-backed components.
  • Write basic unit or integration tests with guidance.
  • Reproduce defects and make focused code improvements.
  • Follow Git workflows and document setup and implementation notes.
What you should bring

Required skills and experience

  • Basic C# syntax and understanding of methods, classes and collections.
  • Introductory object-oriented programming concepts.
  • Programming problem-solving and debugging skills.
  • Willingness to learn ASP.NET Core, data access and testing.
  • Ability to explain relevant coursework or a small project.
Additional strengths

Helpful experience

  • ASP.NET Core, Entity Framework Core or REST APIs.
  • SQL and relational database knowledge.
  • A Git project demonstrating C# or .NET learning.
How contribution is assessed

What success can look like

  • Features and fixes follow project conventions and are tested.
  • The intern can explain data flow through a .NET application.
  • Feedback is applied and implementation notes are current.
