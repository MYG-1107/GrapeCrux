About the opportunity

What this role is about

Learn by contributing to software tasks with guidance. Build small frontend or backend features, test your changes and explain the decisions behind your work.

GrapeCrux values practical problem-solving, clear communication and responsible engineering. The work is shaped around business needs, user outcomes and the quality of the solution delivered.

Before you apply

Use Job ID GC-IN-001 in any follow-up about this opportunity. The application email includes this reference automatically.

GrapeCrux does not charge applicants any application or recruitment fee.

What you'll do

Responsibilities

  • Implement and improve small, clearly scoped application features.
  • Write readable code and follow repository contribution practices.
  • Assist with UI components, API connections, data handling or application fixes.
  • Test changes, reproduce issues and communicate blockers early.
  • Use Git and contribute useful notes or documentation.
  • Learn from code review and apply feedback.
What you should bring

Required skills and experience

  • Basic understanding of at least one programming language and core concepts.
  • Familiarity with HTML, CSS and JavaScript or a relevant equivalent.
  • Basic understanding of Git, debugging and task breakdown.
  • Ability to explain a coursework, personal or academic project.
  • Curiosity, reliability and willingness to ask questions.
Additional strengths

Helpful experience

  • A small deployed project, GitHub repository or working prototype.
  • Exposure to APIs, SQL, a frontend or backend framework.
  • Basic testing, accessibility or secure coding knowledge.
How contribution is assessed

What success can look like

  • Tasks are completed with readable code and appropriate checks.
  • Progress and blockers are communicated early.
  • Feedback is applied and learning is documented.
