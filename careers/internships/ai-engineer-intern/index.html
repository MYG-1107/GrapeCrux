About the opportunity

What this role is about

Support practical AI experiments and application prototypes. Learn how data, model APIs, evaluation and product safeguards come together in useful AI features.

GrapeCrux values practical problem-solving, clear communication and responsible engineering. The work is shaped around business needs, user outcomes and the quality of the solution delivered.

Before you apply

Use Job ID GC-IN-003 in any follow-up about this opportunity. The application email includes this reference automatically.

GrapeCrux does not charge applicants any application or recruitment fee.

What you'll do

Responsibilities

  • Assist with Python prototypes and approved model API integrations.
  • Prepare small datasets, examples or test cases for an AI task.
  • Compare model outputs and record quality, latency and reliability observations.
  • Help build retrieval, document-processing or automation workflows.
  • Add validation, error handling and tests to prototype code.
  • Document experiments, results, limitations and next steps.
What you should bring

Required skills and experience

  • Basic Python programming and familiarity with functions and debugging.
  • Introductory understanding of machine learning, generative AI or data processing.
  • Basic API and JSON concepts.
  • Ability to explain a project or learning exercise.
  • Careful data handling and interest in responsible AI practices.
Additional strengths

Helpful experience

  • Projects using pandas, scikit-learn, notebooks or model APIs.
  • Embeddings, retrieval, vector search or prompt evaluation.
  • Git, FastAPI or frontend integration.
How contribution is assessed

What success can look like

  • Experiments are reproducible and conclusions use observed results.
  • Prototype code is readable and validated.
  • Limitations and risks are communicated.
