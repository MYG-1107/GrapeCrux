About the opportunity

What this role is about

Build practical AI capabilities that connect models with real workflows. Design integrations, retrieval and tool use, evaluate output quality, and make AI-enabled features safer and more dependable.

GrapeCrux values practical problem-solving, clear communication and responsible engineering. The work is shaped around business needs, user outcomes and the quality of the solution delivered.

Before you apply

Use Job ID GC-FT-002 in any follow-up about this opportunity. The application email includes this reference automatically.

GrapeCrux does not charge applicants any application or recruitment fee.

What you'll do

Responsibilities

  • Build AI-enabled application features using Python, model APIs and maintainable backend services.
  • Design retrieval, document-processing, tool integrations or task-specific automation where appropriate.
  • Develop evaluation datasets and checks for relevance, groundedness, safety, latency and cost.
  • Improve prompt, context and orchestration logic using measured results.
  • Apply privacy, access-control, validation and human-review safeguards.
  • Document system behaviour, limitations, operations and failure handling.
What you should bring

Required skills and experience

  • Professional software development experience with strong Python programming skills.
  • Understanding of APIs, data structures and service-based application patterns.
  • Practical knowledge of machine-learning or generative-AI concepts and model limitations.
  • Ability to design test cases, evaluate results and communicate quality limitations.
  • Familiarity with Git, debugging, data handling and secure development.
Additional strengths

Helpful experience

  • LLM APIs, embeddings, vector search, RAG or agent/tool orchestration.
  • ML frameworks, data pipelines, model evaluation or observability.
  • Cloud deployment, containers or production API operations.
How contribution is assessed

What success can look like

  • AI features solve a defined task and are evaluated against explicit criteria.
  • Failures, uncertainty, privacy boundaries and human escalation are considered before release.
  • Systems can be monitored, maintained and improved using evidence.
