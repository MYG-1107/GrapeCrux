About the opportunity

What this role is about

Own meaningful parts of web products from interface to data layer. Shape maintainable architecture, deliver accessible experiences and raise engineering quality through thoughtful implementation and review.

GrapeCrux values practical problem-solving, clear communication and responsible engineering. The work is shaped around business needs, user outcomes and the quality of the solution delivered.

Before you apply

Use Job ID GC-FT-001 in any follow-up about this opportunity. The application email includes this reference automatically.

GrapeCrux does not charge applicants any application or recruitment fee.

What you'll do

Responsibilities

  • Design, build and maintain responsive web applications and reusable frontend components.
  • Develop backend services, REST APIs, integrations, authentication flows and data models.
  • Translate product requirements into technical plans and clear acceptance criteria.
  • Review code, improve standards and resolve complex production or integration issues.
  • Contribute automated tests, observability, performance improvements and secure development practices.
  • Collaborate with design, QA and delivery stakeholders; document technical decisions.
What you should bring

Required skills and experience

  • Demonstrated professional experience delivering and maintaining production web applications.
  • Strong JavaScript or TypeScript and a modern frontend framework such as React, Angular or Vue.
  • Backend development in a language or framework such as Node.js, Python, .NET or Java.
  • Understanding of relational databases, API design, authentication, authorisation and validation.
  • Experience with Git collaboration, code review, debugging and automated testing.
  • Ability to discuss architecture and trade-offs in practical language.
Additional strengths

Helpful experience

  • Cloud platforms, containers, CI/CD or infrastructure-as-code workflows.
  • Caching, queues, background processing, observability or performance profiling.
  • Experience improving accessibility, security or reliability in an existing product.
How contribution is assessed

What success can look like

  • Features are delivered with ownership, useful tests and maintainable implementation.
  • Technical decisions are proportionate to product needs and properly documented.
  • The team gains confidence through thoughtful reviews and collaboration.
