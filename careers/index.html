GrapeCrux invites applications for remote internship tracks across software, AI, data, quality, design and digital growth. The programme is structured around supervised work, practical learning and clear deliverables.

Internship tracks

Choose the area where you want to grow.

Applicants may select the role that best matches their current skills and learning goals. Specific openings, mentors and start dates are confirmed during selection.

ROLE / 01Remote · 3 months

Software Development Intern

Frontend, backend or full-stack

Contribute to scoped website and application tasks, build small features, review pull requests with a mentor, write basic tests and document implementation decisions.

Who should apply?

Students or recent graduates with fundamentals in HTML, CSS, JavaScript or a backend language; familiarity with Git and APIs is helpful.

ROLE / 02Remote · 3 months

AI / Machine Learning Intern

Applied AI, model evaluation and automation

Support small experiments, prepare and inspect datasets, test prompts or model outputs, prototype AI-enabled workflows and document limitations and evaluation results.

Who should apply?

Python fundamentals, data handling and basic ML concepts. Responsible handling of data and willingness to test failure cases are important.

ROLE / 03Remote · 3 months

Data Analytics Intern

Data preparation, analysis and dashboards

Clean structured data, validate data quality, perform exploratory analysis, prepare clear visual summaries and document assumptions behind metrics.

Who should apply?

Comfort with spreadsheets or SQL; Python and visualisation skills are useful. Clear written communication is expected.

ROLE / 04Remote · 3 months

Quality Assurance & Test Automation Intern

Functional testing and software quality

Create test scenarios, verify responsive pages and forms, report reproducible defects, retest fixes and explore suitable browser automation tools.

Who should apply?

Careful observation, structured reporting and basic web knowledge. Familiarity with test cases, browser tools or automation is an advantage.

ROLE / 05Remote · 3 months

UI / UX Design Intern

Research, wireframes and interface design

Help map user journeys, organise information, create wireframes and prototypes, collect feedback and maintain consistent interface components.

Who should apply?

Interest in usability and visual communication; familiarity with Figma or similar design tools is useful.

ROLE / 06Remote · 3 months

Cloud & DevOps Intern

Deployment and operational reliability

Assist with documented build/deploy workflows, environment configuration, monitoring checks, release notes and basic troubleshooting under supervision.

Who should apply?

Linux and Git fundamentals; introductory cloud, containers or CI/CD knowledge is helpful.

ROLE / 07Remote · 3 months

Business & Digital Marketing Intern

Content, SEO and business research

Research audiences and keywords, prepare content briefs, support blog publishing, review basic website analytics and organise business-development research.

Who should apply?

Strong writing and communication skills, attention to detail and interest in digital marketing and technology services.

Programme details

Clear expectations from day one.

Duration

Three months, with the start and end dates stated in the written offer.

Work arrangement

Remote / work from home within India. Work is coordinated online with scheduled team check-ins.

Time commitment

Expected commitment is approximately 20 hours per week, normally across five weekdays. The final schedule is agreed before joining.

Indicative stipend

₹5,000–₹10,000 per month, depending on role, demonstrated skills and assigned scope. The confirmed amount and payment terms will be stated in the written offer.

Learning and feedback

Task guidance, review checkpoints, practical documentation and feedback from the assigned supervisor.

Completion certificate

A certificate may be issued after successful completion of the agreed duration, deliverables and participation requirements.

Before accepting: The stipend shown is indicative. Your written offer will confirm the approved amount, payment schedule, start and end dates, weekly hours, mentor and assigned responsibilities. Internship completion does not guarantee a permanent role or placement. There is no application, recruitment or security fee.

Who should apply?

Curiosity matters. So does reliability.

These tracks are intended for students, recent graduates and early-career learners who want supervised experience. We value fundamentals, clear communication, responsible handling of information, willingness to ask questions and the ability to complete agreed tasks.

Applicants should have reliable internet access, a computer suitable for the chosen role and availability for the agreed weekly schedule.

Never pay an application, recruitment or security fee. GrapeCrux should not request passwords, banking PINs or one-time passcodes during recruitment.
